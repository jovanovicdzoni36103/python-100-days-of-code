For Day 19 of the Python bootcamp, I built two mini-games using Turtle graphics to learn interactive programming. First, I made an Etch-A-Sketch app where you control the drawing turtle using W, A, S, and D keys, with C clearing the screen. After that, I built a turtle race game where you bet on a color via a pop-up prompt, and six turtles race to the finish line with random step sizes while the console prints the winner. Along the way, I learned how event listeners work, how to pass functions as arguments without parentheses, and how multiple object instances keep track of their own independent state.
