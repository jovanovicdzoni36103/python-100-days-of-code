# yu_100days

Sav kod sa kursa 100 Days of Code: The Complete Python Pro Bootcamp (Angela Yu).

## Struktura

Jedan folder po danu: day_001, day_002, i tako redom. U folderu stoji main.py i, ako dan ima projekat, ostali fajlovi tog dana.

## Pravilo

Svaki dan se komituje istog dana kada je odrađen. Poruka komita: day NNN, pa kratak opis.

## Napomena

Ovo je repo za vežbu, ne portfolio. Portfolio projekti idu u zasebne repoe, a plan i napredak stoje u repou ai_journey.
