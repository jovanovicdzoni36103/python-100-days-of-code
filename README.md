# yu_100days

All code from the course 100 Days of Code: The Complete Python Pro Bootcamp (Angela Yu).

## Structure

One folder per day: day_001, day_002, and so on. Inside the folder is main.py and, if the day includes a project, the other files for that day.

## Rule

Each day is committed on the day it is completed. Commit message format: day NNN, followed by a short description.

## Note

This is a repository for practice, not a portfolio. Portfolio projects go into separate repositories, while the plan and progress are tracked in the ai_journey repository.
