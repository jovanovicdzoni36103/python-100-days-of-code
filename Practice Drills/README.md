# Practice Drills

Forty eight exercises I wrote for myself, outside the course. When a topic did not
stick the first time I came back here and drilled it until it did, so these are not
tied to any single course day.

**Levels:** 4  
**Tasks:** 48  
**Status:** Completed

| File | Level | Tasks | What it covers |
|---|---|---|---|
| level_1_osnovna_logika.py | 1 | 1 to 10 | Basic logic, input and output, arithmetic |
| level_2_kombinovanje_koncepata.py | 2 | 11 to 22 | Combining concepts, loops over accumulated values |
| level_3_funkcije_i_algoritmi.py | 3 | 23 to 34 | Functions and algorithmic thinking |
| level_4_state_i_validacija.py | 4 | 35 to 48 | State, validation and longer problems |

Each task keeps its own comment header with the original wording, so the file reads
as a worksheet rather than a finished program.
