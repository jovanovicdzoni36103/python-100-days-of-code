# Course Mapping

This repository uses two numbering systems. They are not the same and they are not meant to match.

**Learning Day** is my own plan. It counts working days from 17 August 2026 and runs to 260. It includes setup days, Git days, consolidation days and later phases that have nothing to do with this course.

**Course Day** is Angela Yu's numbering inside *100 Days of Code: The Complete Python Pro Bootcamp*. It counts lessons in the course, not days of my life.

**The folders in this repo are named after the Course Day.** `day_007` is Angela Yu Day 7, which I did on my Learning Day 9. Commit messages that start with `dan NNN` refer to the Learning Day. That is the one thing to know before reading anything else here.

Some course days are skipped on purpose. The reason is written in the table.
